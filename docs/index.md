## Project Overview

Calibre-Web-AI is a Python Flask web application that extends the original Calibre-Web project with AI-powered discovery features. The application provides a web interface for browsing, reading, and downloading eBooks stored in a Calibre database, with plans to add AI-generated book summaries, semantic search, and similar book recommendations.

The codebase is a monolithic Flask application using server-side rendering with Jinja2 templates, SQLAlchemy for database access, and a modular blueprint-based architecture.

## Quick Reference

- **Tech Stack:** Python 3.8+, Flask, SQLAlchemy, Jinja2, Tornado
- **Entry Point:** `cps/main.py` → `main()` function
- **Architecture Pattern:** Blueprint-based modular Flask application
- **Database:** SQLAlchemy ORM with dual-database approach (user DB + Calibre DB)
- **Deployment:** WSGI application (Tornado, or Gunicorn/uWSGI in production)

## Getting Started

### Prerequisites

- Python 3.7 or newer
- Imagemagick (for cover extraction)
- Calibre desktop program (optional)

### Setup

```bash
# Create virtual environment
python3 -m venv calibre-web-env

# Activate virtual environment
source calibre-web-env/bin/activate  # Linux/macOS
# or
calibre-web-env\Scripts\activate    # Windows

# Install Calibre-Web
pip install calibreweb
```

### Run Locally

```bash
# Start development server
cps

# Access at http://localhost:8083
# Default credentials: admin / admin123
```

### Run Tests

```bash
# Unit tests (if available locally)
python -m pytest

# Note: Main test suite is in separate repository
# https://github.com/OzzieIsaacs/calibre-web-test
```

### Key Integration Points

- **Flask Application:** `cps/__init__.py` → `create_app()`
- **Main Entry:** `cps/main.py` → `main()`
- **Database Models:** `cps/ub.py` (user DB), `cps/db.py` (Calibre DB)
- **Blueprints:** Route modules in `cps/` root
- **Services:** Background services in `cps/services/`
- **Templates:** Jinja2 templates in `cps/templates/`
- **Static Assets:** Frontend files in `cps/static/`

### Architecture Notes

- **Blueprint Pattern:** Each major feature has its own blueprint module
- **Dual Database:** User database (ub) and Calibre database (calibre_db)
- **Service Layer:** Business logic separated into services directory
- **Task System:** Background tasks use APScheduler
- **Configuration:** SQL-based configuration with encryption
